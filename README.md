# Организатор медиатеки с защитой торрентов

[![Tests](https://github.com/ginginohf/torrent-safe-media-organizer/actions/workflows/tests.yml/badge.svg)](https://github.com/ginginohf/torrent-safe-media-organizer/actions/workflows/tests.yml) · [MIT](LICENSE)

Нормализует имена свободных файлов и подбирает внешние аудиодорожки, защищая пути, известные qBittorrent.

Редакция 0.1.0 под лицензией MIT. Не содержит настроек конкретного сервера и пользовательских данных. Это самостоятельная адаптация, а не побитная копия рабочего развёртывания.

## Требования

Linux/POSIX, Python 3.11+, читаемые пары .torrent/.fastresume qBittorrent.

## Развёртывание

Скачайте проект:

```sh
git clone https://github.com/ginginohf/torrent-safe-media-organizer.git
cd torrent-safe-media-organizer
```

Следующие команды выполняются из корня репозитория. Не используйте production-данные для первого запуска.

```sh
export MEDIA_ROOT=/srv/media
export TORRENT_METADATA=/srv/qbittorrent/BT_backup
export ORGANIZER_STATE=state
python3 organize.py
# Только после просмотра плана и резервирования:
python3 organize.py --apply
```

## Настройки и ограничения

По умолчанию preview. Нет метаданных или повреждена пара — безопасный отказ. MEDIA_ROOT должен совпадать с реальным корнем, контейнерные пути /media и /downloads преобразуются относительно него. Перемещения выполняются hardlink+unlink, поэтому нужна одна ФС. Автоматического отката перемещений пока нет: сначала копия медиатеки. Не использовать одновременно со скачиванием/изменением торрент-метаданных.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Для проектов с requirements.txt сначала установите зависимости в виртуальное окружение. Результаты локальных проверок и ограничения — в TESTING.md. CI предназначен для Linux; аппаратные счётчики и реальные диски в CI не эмулируются.

## Обновление и откат

Сохраните конфигурацию и данные отдельно от кода. Остановите только этот экземпляр, замените код, выполните тесты, запустите снова. Не переносите тестовые базы поверх рабочих. Подробности — RESTORE.md.

## Приватность и публикация

.env/config.json, базы, журналы, state и зависимости исключены из Git. Игнорирование не очищает уже закоммиченные данные: перед push повторите аудит. README-примеры не содержат действующих учётных данных. См. SECURITY.md, CONTRIBUTING.md, THIRD_PARTY.md. Собственный код распространяется по [MIT](LICENSE). Сторонние компоненты сохраняют свои условия.
